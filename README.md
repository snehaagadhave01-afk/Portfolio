# 🌐 Personal Portfolio Website

## 📌 About
A personal portfolio website to showcase my resume, projects, technical skills, and contact information in one place.

## ✨ Features
- 🏠 **Home:** Introduction and welcome section.
- 👤 **About Me:** Information about my background.
- 📄 **Resume:** Education, experience, and qualifications.
- 💻 **Projects:** Showcase of my projects and work.
- 🛠️ **Skills:** Technical skills and technologies.
- 📩 **Contact:** Contact details and communication options.
- 📱 **Responsive Design:** Accessible on different screen sizes (if implemented).

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
